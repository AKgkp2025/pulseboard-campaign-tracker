# Pulseboard campaign tracker

A lightweight, spreadsheet-style daily campaign tracker for recording spend, leads, revenue, and payout status.

## Run it

Open `index.html` in a modern browser. The app is dependency-free and stores entries in the browser's `localStorage`.

## Included in this first slice

- Daily date navigation with a focused campaign table
- KPI cards for spend, revenue, ROAS, and pending payouts
- Add campaign modal with validation-friendly numeric fields
- One-click paid/pending payment updates
- Search and payment-status filtering
- CSV export for the selected day
- Seeded example rows so the screen is useful on first open

This is currently a local single-user prototype; it does not yet include login, a shared backend, or real payment processing.
